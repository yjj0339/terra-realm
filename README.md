# 泰拉之境 · Terra Realm

一款可完整通关的泰拉瑞亚式 2D 沙盒冒险游戏。原生 HTML5 Canvas + JavaScript，无外部依赖、无网络请求。

## 在线游玩

**https://yjj0339.github.io/terra-realm/**

手机、平板、电脑浏览器直接打开即可。也可以克隆仓库后双击 `index.html` 离线运行。

- 手机建议横屏；进入后左下角是虚拟摇杆，右下角是跳跃 / 挖掘 / 放置 / 背包 / 喝药按钮。
- 桌面用键盘鼠标；首次点击后才会启动音频（浏览器策略，非缺陷）。
- 想确认线上是不是最新版：`Ctrl+F5` 强制刷新（Pages 有 10 分钟缓存）。

## 核心系统

**彩色光照引擎**
- 逐 4px 单元的光线传播：天空光按地表线注入，横穿方块时受遮挡衰减
- 彩色光源叠加：火把橙、岩浆红、生命水晶粉、魔力水晶蓝、狱石赤红、玩家暖白
- 乘法合成，带遮蔽的洞穴环境光，白天进洞不会被一刀切黑

**世界生成**
- 1600 × 1000 方块，输入种子可复现
- 13 个生态区：海洋、海滩、地牢、森林、雪原、腐化之地、丛林、沙漠、空岛、洞穴、地下、深渊、地狱
- 分层地层、噪声洞穴、9 条地表竖井
- 12 类矿石 + 7 种宝石：铜/锡/铁/铅/银/钨/金/铂金/恶魔/血金/陨石/狱石，紫水晶/黄玉/翡翠/红玉/蓝宝石/钻石/琥珀
- 3 座浮空岛（含云屋与专属宝箱）、4 座恶魔祭坛、26 座地下小屋
- 地牢：入口大厅 + 竖向主井 + 4 间房，带平台与火把照明
- 海洋、地下水潭、地狱岩浆海，水与岩浆接触生成黑曜石

**画面**
- 每个生态独立的天空配色 + 三层视差远山（随昼夜变暗）
- 太阳带光晕、月相按天数变化、星空闪烁、飘动云层
- 雨 / 雪 / 雷暴天气，按生态自动切换；雷暴有闪电与雷声
- 瓦片按相邻关系绘制边缘高光、暗部、草皮颗粒；树冠为圆润团块并带体积阴影
- 角色为分层骨骼动画：四肢独立绕关节旋转、行走摆动、持武姿势、护甲分层染色
- 敌怪独立造型：史莱姆带高光与瞳孔、骷髅/僵尸/蚁狮/鱼/飞行怪各有结构
- NPC 各有装束特征（商人帽、护士十字、巫师尖帽、树妖藤蔓等）
- 粒子系统：挖掘碎屑、受伤血花、暴击数字、落叶、水花、烟雾、光点

**玩法与正版规则**
- 挖掘 / 放置 / 砍树 / 拆墙，镐斧锤三类工具分级
- **树干可穿行**：与正版一致，树干不阻挡移动，但仍可用斧头砍伐，砍倒后整棵树的木头一并掉落
- **镐力门槛**：恶魔矿、狱石、黑檀石、地牢砖等需要对应威力的镐，镐不够会提示挖不动
- 近战 / 弓 / 枪 / 魔法 / 召唤五类武器；弹药与魔力消耗、召唤物自动索敌
- 攻击有 ±15% 伤害浮动与暴击（暴击双倍并显示金色数字）
- **死亡掉落一半金币**，散落在尸体旁可捡回
- **抓钩**：右键发射、黏住方块或树干后把玩家拽过去，松开即脱钩
- **翅膀**：按住空格持续飞行，落地回充
- **魔镜**：右键瞬间传送回出生点
- 护甲按头/身/腿分层，18 套套装共 54 件；30 种饰品（二段跳、冲刺、免疫摔落、生命恢复、魔力强化、伤害加成、跳跃强化、翅膀飞行、黑曜石盾、免疫岩浆、免疫击退等）
- 12 种药水：弱效/普通/强效治疗、魔力、铁皮、迅捷、夜猫子、再生、黑曜石皮肤、挖矿、蜂蜜、回城

**战斗**
- 6 场 Boss 战
  - 克苏鲁之眼：两阶段，冲刺 + 环形弹幕
  - 世界吞噬者：多节段，可逐节打断
  - 骷髅王：双拳独立血量、旋转冲刺
  - 血肉之墙：贴屏追击、三眼激光、牙齿实体
  - 史莱姆王：跳跃砸地、分裂小史莱姆、二阶段瞬移
  - 蜂后：悬停编织、蓄力俯冲、扇形毒刺
- 33 种敌怪，按生态与深度分配刷怪池；夜间敌人更强
- 7 位 NPC 随进度入住，提供商店、治疗、提示
- 4 类事件：血月、史莱姆雨、流星雨、哥布林入侵

**界面**
- 心形生命 / 星形魔力 / 增益条 / 时钟与生态 / Boss 血条
- 实时迷你地图（地形、NPC 绿点、敌人红点、Boss 标记、深度）
- 世界地图（探索迷雾、玩家位置、Boss 位置）
- 背包 / 装备 / 制作（10 类分类筛选）/ 箱子 / NPC 商店
- 暂停、操作指南、胜利结算
- localStorage 存档（RLE 压缩，约 560 KB），自动存档 + 手动存档

**音频**
- 程序化音效：挖掘、破碎、挥砍、射击、魔法、受伤、击杀、Boss、雷声
- 自适应配乐：白天 / 夜晚 / 地下 / 地狱 / 雪原 / 沙漠 / 丛林 / 腐化 / Boss 九套音阶与节奏

### 桌面

| 移动 | A / D |

| 放置 / 交互 / 抓钩 / 魔镜 | 鼠标右键 |

| 丢弃手持物 | T |
| 回到出生点 | R |
| 世界地图 | M |

```
js/content_more.js  扩展物品与配方（117 件 / 117 条）

js/icons.js         程序化物品图标
js/audio.js         程序化音效与配乐
js/entities.js      敌人、Boss、弹幕、掉落物、召唤物、NPC
js/player.js        玩家物理、挖建、战斗、抓钩、翅膀、背包

preview/            预览截图
```

## 说明

本项目的所有美术、图标、音效、配乐均由代码程序化生成，不含任何泰拉瑞亚（Terraria / Re-Logic）的官方素材。玩法与系统设计参考了该类型的通行做法。
