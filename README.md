# 泰拉之境 · Terra Realm

一款可完整通关的泰拉瑞亚式 2D 沙盒冒险游戏。原生 HTML5 Canvas + JavaScript，无外部依赖、无网络请求，双击 `index.html` 即可运行。

## 在线游玩

https://yjj0339.github.io/terra-realm/

## 运行

直接双击 `index.html`（推荐 Chrome / Edge）。音频在首次点击后启动，这是浏览器策略，不是缺陷。

## 核心系统

**彩色光照引擎**
- 逐 4px 单元的光线传播：天空光按地表线注入，横穿方块时受遮挡衰减
- 彩色光源叠加：火把橙、岩浆红、生命水晶粉、魔力水晶蓝、狱石赤红、玩家暖白
- 乘法合成，带遮蔽的洞穴环境光，所以白天进洞不会被一刀切黑

**世界生成**
- 1600 × 1000 方块，输入种子可复现
- 13 个生态区：海洋、海滩、地牢、森林、雪原、腐化之地、丛林、沙漠
- 分层地层、噪声洞穴、9 条地表竖井、7 类矿石 + 4 种宝石
- 3 座浮空岛（含云屋与专属宝箱）、4 座恶魔祭坛、26 座地下小屋
- 地牢：入口大厅 + 竖向主井 + 4 间房，带平台与火把照明
- 海洋、地下水潭、地狱岩浆海，水与岩浆接触生成黑曜石

**画面**
- 每个生态独立的天空配色 + 三层视差远山（随昼夜变暗）
- 太阳带光晕、月相按天数变化、星空闪烁、飘动云层
- 雨 / 雪 / 雷暴天气，按生态自动切换；雷暴有闪电与雷声
- 瓦片按相邻关系绘制边缘高光、暗部与草皮细节；树冠有体积阴影
- 角色为分层骨骼动画：四肢独立绕关节旋转、行走摆动、持武姿势、护甲分层染色
- 敌怪独立造型：史莱姆带高光与瞳孔、骷髅/僵尸/蚁狮/鱼/飞行怪各有结构
- NPC 各有装束特征（商人帽、护士十字、巫师尖帽、树妖藤蔓等）
- 粒子系统：挖掘碎屑、受伤血花、暴击数字、落叶、水花、烟雾、光点

**玩法**
- 挖掘 / 放置 / 砍树 / 拆墙，镐斧锤三类工具分级
- 174 件物品、113 条配方、6 个制作站、10 类制作分类筛选
- 近战 / 弓 / 枪 / 魔法 / 召唤五类武器；弹药与魔力消耗、召唤物自动索敌
- 11 套护甲、10 种饰品（二段跳、冲刺、免疫摔落、生命恢复、魔力强化、伤害加成、跳跃强化、翅膀飞行、黑曜石盾、徽章）
- **抓钩**：右键发射、黏住方块后把玩家拽过去，松开即脱钩
- **翅膀**：按住空格持续飞行，落地回充
- **魔镜**：右键瞬间传送回出生点
- 8 种药水：治疗、魔力、铁皮、迅捷、夜猫子、再生、黑曜石皮肤、挖矿

**战斗**
- 6 场 Boss 战
  - 克苏鲁之眼：两阶段，冲刺 + 环形弹幕
  - 世界吞噬者：多节段，可逐节打断
  - 骷髅王：双拳独立血量、旋转冲刺
  - 血肉之墙：贴屏追击、三眼激光、牙齿实体
  - 史莱姆王：跳跃砸地、分裂小史莱姆、二阶段瞬移
  - 蜂后：悬停编织、蓄力俯冲、扇形毒刺
- 33 种敌怪，按生态与深度分配刷怪池；夜间敌人更强
- 7 位 NPC 随进度入住，提供商店、治疗、提示
- 4 类事件：血月、史莱姆雨、流星雨、哥布林入侵

**界面**
- 心形生命 / 星形魔力 / 增益条 / 时钟与生态 / Boss 血条
- 实时迷你地图（地形、NPC 绿点、敌人红点、Boss 标记、深度）
- 世界地图（探索迷雾、玩家位置、Boss 位置）
- 背包 / 装备 / 制作（分类筛选）/ 箱子 / NPC 商店
- 暂停、操作指南、胜利结算
- localStorage 存档（RLE 压缩，约 0.6 MB），自动存档 + 手动存档

**音频**
- 程序化音效：挖掘、破碎、挥砍、射击、魔法、受伤、击杀、Boss、雷声
- 自适应配乐：白天 / 夜晚 / 地下 / 地狱 / 雪原 / 沙漠 / 丛林 / 腐化 / Boss 九套音阶与节奏

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | A / D |
| 跳跃 / 二段跳 | 空格 |
| 飞行（需翅膀） | 按住空格 |
| 下落穿平台 | S + 空格 |
| 攀爬绳子 | W / S |
| 冲刺（需靴子） | Shift |
| 挖掘 / 攻击 / 使用 | 鼠标左键 |
| 放置 / 交互 / 抓钩 / 魔镜 | 鼠标右键 |
| 背包与制作 | E |
| 快捷栏 | 1–0 / 滚轮 |
| 快速治疗 / 魔力 | Q / F |
| 丢弃手持物 | T |
| 回到出生点 | R |
| 世界地图 | M |
| 暂停 | Esc |

## 通关路线

砍树 → 工作台 → 铜镐 → 洞穴找生命水晶与矿石 → 史莱姆王冠召唤史莱姆王 → 丛林蜂巢诱饵挑战蜂后 → 腐化之地收集暗影鳞片 → 夜晚召唤克苏鲁之眼 → 恶魔祭坛制作腐化诱饵 → 地牢挑战骷髅王 → 地狱挖狱石 → 把向导巫毒娃娃投入岩浆唤醒血肉之墙。

## 文件结构

```
index.html          入口
css/style.css       macOS 风格界面
js/util.js          工具、噪声、RLE
js/tiles.js         方块与墙体定义
js/items.js         物品与配方
js/world.js         世界生成、液体模拟、光照烘焙
js/gfx.js           瓦片烘焙、区块缓存、天空、背景、天气
js/lighting.js      彩色光照引擎
js/icons.js         程序化物品图标
js/audio.js         程序化音效与配乐
js/entities.js      敌人、Boss、弹幕、掉落物、召唤物、NPC
js/player.js        玩家物理、挖建、战斗、抓钩、翅膀、背包
js/ui.js            HUD、迷你地图、面板、大地图
js/game.js          主循环、系统编排、存档
preview/            预览截图
```
